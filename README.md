# Nick's dotfiles

This repo contains the configuration files for my personal setup. Currently working on MacOS, but soon on Linux and Windows as well.

## Installation
You can either install [chezmoi](https://www.chezmoi.io/) using any of the available options, or you can directly deploy the dotfiles with the following oneliner:

``` sh
sh -c "$(curl -fsLS get.chezmoi.io)" -- init --apply nickfaraco
```
